# Instructor solution 03 — Recover without resetting state

Use after the independent attempt.

On the first run the foundation output is unknown at plan time. Foundation creation succeeds and is recorded; then the release precondition fails. Set readiness=ready, save a fresh plan, review one foundation update and one release create, and apply it. The foundation ID remains the same. A missing binding calls for verifying/importing an existing object; lost application data calls for the application backup, not a state restore. A student who deletes state has bypassed the learning outcome.
