# Instructor solution 07 — Predict idempotence

Use after the independent attempt.

The reference escapes title, environment and message. Extra variables override the play-level environment. First render changes a file; the second identical run changes nothing. Check mode with prod predicts a difference but leaves staging on disk. On the real host, only configuration changes notify the shared validation/reload handlers; template changes for a static page need no service restart. Package and command behavior in check mode is incomplete, so use a disposable integration host for first-install verification.
