# Instructor solution 01 — Design ownership

Use after the independent attempt.

Terraform owns VPC, subnets, routing, SG, key pair and EC2; Ansible owns Nginx, its configuration and page. An operator needs a route through the internet gateway, a public IPv4 on the instance, a security-group rule for the operator /32 and a listening service. Private subnets have no direct internet route. Source lives in Git, state in a restricted versioned backend, credentials in the identity system, and runtime data needs its own backup policy. A single EC2 in one AZ is a deliberate teaching limit, not high availability.
