# Instructor solution 04 — Demonstrate isolation

Use after the independent attempt.

The reference has two roots and two state files. Updating dev must not change the prod output or plan. In AWS, use distinct keys and restrict each role to its own key/lock plus its own resource/account scope. Anyone authorized for both keys can still operate on both: naming is not authorization. A backend is selected at init; changing a variable does not select another backend.
